# Saran Developer Portfolio

Fresh, clean, Vercel-ready static portfolio.

## Files

- `index.html` — main page
- `style.css` — design and responsive layout
- `profile.jpg` — replace with your own profile image

## Deploy

1. Create a new GitHub repository.
2. Upload all files.
3. Make sure `index.html` is in the repository root.
4. Import the repository into Vercel.
5. Deploy.

No environment variables are required for this portfolio.
